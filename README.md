### About me

I'm a full stack and AI engineer from Roorkee, India. I build AI agents and the tooling around them, mostly in TypeScript, and lately some Go.

- 💼 Shipping production SaaS as Full-Stack AI Developer at **OVOLO IT Building Solutions**, Backend Developer at **Secure Blink** (cybersecurity), and Full-Stack + DevOps Developer at [Zero One Creation](https://github.com/Zero-One-Creation)
- ⚡ Working on agent harnesses, LLM memory, and browser automation for agents
- 🔭 Exploring LangGraph, the Vercel AI SDK, vector search, and Go
- 📚 MCA at Chandigarh University · 800+ DSA problems solved
